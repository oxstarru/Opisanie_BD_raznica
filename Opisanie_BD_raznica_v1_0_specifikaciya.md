# Спецификация утилиты — Описание БД — разница

---

## Паспорт

- **Номер:** № 3 (сквозной по реестру утилит)
- **Название:** Описание БД — разница
- **Версия:** 1.0
- **Категория:** для системного аналитика
- **Автор идеи:** Оксана Старкова
- **Реализация (вайб-код):** ИИ2-2 (создание), ИИ10 (безопасность и стандарт), ИИ10-2 (иконка, исправление сравнения, SQL-запрос, общий разбор таблиц)
- **Дата создания / доработок:** 08.06.2026 (создание) · 08.07.2026 (безопасность + стандарт, 0.4) · 10.08.2026 (доработка и первая итоговая версия, 1.0)
- **Тип:** single-file HTML
- **Приватность:** полностью локально (в сеть ничего не уходит)

## Назначение

Утилита сравнивает две выгрузки метаданных базы данных, сделанные в разные моменты времени, и формирует описание различий: добавленные, удалённые и изменённые таблицы и поля. Предназначена для отслеживания эволюции структуры БД за период и наполнения базы знаний.

## Вход и выход

- **Вход:** два файла — «базовая версия» (более ранняя выгрузка) и «новая версия» (более поздняя). Формат `.xlsx` / `.xls` / `.csv` с колонками структуры БД, полученными **одним и тем же** SQL-запросом. Обязательные колонки: «Схема», «Таблица», «Поле».
- **Выход:** сводка на экране (добавлено / изменено / удалено) с цветовой маркировкой и предпросмотром; ZIP-архив с Markdown-описанием различий.

## Функциональность

- Блок «Откуда взять файл» на первом шаге: готовый SQL-запрос для PostgreSQL с кнопкой копирования, порядком действий и требованием снимать обе выгрузки одним запросом. Свёрнут по умолчанию.
- Загрузка двух выгрузок (перетаскиванием или выбором файла).
- Разбор `.xlsx` и `.csv` — общий блок разбора таблиц (см. ниже).
- Сопоставление таблиц и полей двух выгрузок по именам «схема → таблица → поле».
- Классификация изменений: добавлено, изменено, удалено — с цветовой маркировкой.
- **Сравнение полей только по колонкам, которые есть в обеих выгрузках.** Расхождение наборов колонок показывается отдельным предупреждением на экране и в шапке отчёта, с перечислением, какие колонки только в базовой, какие только в новой.
- Проверка обязательных колонок на входе с внятной ошибкой.
- Предпросмотр результата, скачивание архивом, кнопка «Очистить».

## Технические детали

- Стек: HTML + CSS + JavaScript. Сборка результата — встроенный JSZip.
- **Общий блок разбора таблиц (версия блока 2, 10.08.2026)** — единый код для утилит № 1, № 3, № 4, № 7, побайтово одинаковый во всех четырёх. Умеет: определение разделителя CSV вне кавычек по стабильности числа колонок; склейку многострочных значений в кавычках; экранированные кавычки; снятие BOM; выбор первого листа `.xlsx` по порядку из книги, а не по имени файла; пустые строки листа; inline-строки.
- Внешних библиотек и CDN нет: ранее использовавшийся SheetJS (0.18.5, с уязвимостями) удалён, JSZip встроен локально, Google Fonts убраны.
- Хранение данных: нет (всё в памяти вкладки).
- Обращения в сеть: нет. Шрифты системные.
- Браузеры: любые современные.
- Ограничения: сравнение по именам — переименование поля видится как удаление плюс добавление; SQL-запрос в утилите для PostgreSQL; очень большие выгрузки обрабатываются в памяти вкладки.

## Оформление

Соответствует «Стандарту оформления утилит»: кремово-терракотовая палитра (+ цвета маркировки добавлено / изменено / удалено), системные шрифты + серифный заголовок (Georgia/Iowan Old Style), номер «№ 03» в правом верхнем углу, двухстрочный футер с версией и ссылками, иконка-искра вшита в base64 (4 размера: 16/32/48/64), версия в имени файла через подчёркивание (`Opisanie_BD_raznica_v1_0.html`). Отклонений нет.

## История версий

> Накопительный раздел. Новая финальная версия добавляется сверху; прежние записи не переписываются. В историю попадают только финальные версии — правки промежуточных сборок свёрнуты в запись той версии, которой они завершились.

### Версия 1.0 (10.08.2026, ИИ2-2, ИИ10, ИИ10-2)

Первая версия. Функциональность описана выше.

*Путь до неё: базовая сборка 0.3 (08.06.2026, ИИ2-2) — сравнение двух выгрузок. Сборка 0.4 (08.07.2026, ИИ10) — удалён внешний SheetJS с CDN и Google Fonts, разбор `.xlsx` переписан на встроенный офлайн-парсер, добавлен CSV, убраны обращения в сеть; оформление приведено к стандарту, номер исправлен «№ 06» → «№ 03» по реестру. Сборки 0.5–0.6 (10.08.2026, ИИ10-2) — исправление сравнения по колонкам, проверка обязательных колонок, SQL-запрос в утилите, общий блок разбора таблиц, иконка, кнопка «Очистить».*

**Что было исправлено на пути к первой версии — важно для будущих доработок:**

- **Сравнение полей шло по объединению колонок обеих выгрузок.** Стоило в новой выгрузке появиться одной колонке (например, в SQL-запрос добавили «Комментарий») — и у каждого поля возникала разница «было пусто → стало что-то»: изменёнными объявлялись все поля всех таблиц подряд, включая нетронутые. Отчёт становился бесполезным. Теперь сравнение только по общим колонкам, расхождение наборов показывается предупреждением на экране и в шапке отчёта.
- **Обязательными считались только «Схема» и «Таблица».** Если колонка полей называлась иначе, утилита молча сравнивала таблицы «без полей» и отчитывалась «изменений нет» — тихая неправда. Теперь проверяется и «Поле», с внятной ошибкой.
- **Выбор листа `.xlsx`** определялся сортировкой по имени файла (`sheet1`, `sheet10`, `sheet2`) — мог разбираться не тот лист. Исправлено в общем блоке разбора.
- **Скачивание архива** могло прерваться в Firefox и Safari: адрес блоба освобождался сразу после клика.

**Технические примечания**

- Общий блок разбора таблиц (версия блока 2) — единый код для утилит № 1, № 3, № 4, № 7, побайтово одинаковый во всех четырёх. Закрывает пункт «переиспользовать разбор с утилитой № 1».
- Сравнение принимает список общих колонок параметром (`diffTable(oldT, newT, compareKeys)`), расхождение возвращается в `cols` вместе с результатом.
