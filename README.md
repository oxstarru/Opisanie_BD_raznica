# Opisanie_BD_raznica
Утилита сравнивает две выгрузки структуры базы данных, сделанные в разное время (например, на 1 июня и на 1 июля), и показывает, что изменилось: какие таблицы и поля добавились, какие удалились, какие изменились. Удобно, когда нужно понять, как база менялась за период, и задокументировать это для базы знаний.
